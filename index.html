WorldAFX: Content-Invariant
Audio Effect Representations

1Smule, Inc.    2UC San Diego

Abstract

We present WorldAFX, a system that learns to represent audio effects — such as equalization, dynamic compression, saturation, and reverberation — directly from dry/wet audio pairs, without access to plugin parameter labels. Our key insight is that a content-invariant representation can be learned by training on pairs where the same effect is applied to different source audio, forcing the encoder to capture only the effect's character and not the content. At inference time, given a dry signal and a reference wet recording, WorldAFX predicts the effect parameters needed to match the reference. We evaluate across a diverse set of professional VST3 plugins spanning multiple effect categories and demonstrate strong reconstruction quality both via objective metrics and a MUSHRA listening study.

Method

WorldAFX uses a factorized architecture: a shared audio encoder maps a wet reference clip to a tone embedding, and each DSP module (EQ, compressor, saturator, reverb) contains its own lightweight MLP that reads from this embedding to predict its plugin parameters. A differentiable neural nonlinearity handles residual timbral shaping beyond what the DSP modules capture. The entire system is trained end-to-end on content-invariant pairs — the reference and target use the same audio effect settings applied to different source recordings — preventing the encoder from memorizing content and ensuring the tone embedding captures only effect character.
