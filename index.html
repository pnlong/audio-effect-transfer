Abstract

Musicians and mixing engineers often can decipher the signal processing chain they hear on a reference recording, then adapt it to new material. We present TAPE (Transformations of Audio Parameter Embeddings), which estimates this processing from the processed reference audio alone. An encoder trained to identify processors in eight major effect families maps the reference to an embedding. A differentiable digital signal processing (DSP) chain decodes the embedding into editable parameters in one forward pass and applies them to a different unprocessed recording. Its modules are equalization, compression, waveshaping, a small residual network, and reverberation. TAPE achieves lower spectral error than the previous state of the art for both single-step regression and multi-step search, while running 275× faster than the multi-step approach. Because the decoder outputs DSP parameters, its chain can also run causally: a C++ implementation with the trained weights processed 128-sample buffers 1.8× faster than real time, with no missed deadlines.

Method

TAPE (Transformations of Audio Parameter Embeddings) uses a shared audio encoder that maps a wet reference clip to an embedding z ∈ ℝ256 that does not depend on the source it was heard on. To decode z into human-readable primitives for signal shaping, the inverse g is a factorized differentiable chain of DSP modules for equalization, compression, waveshaping, residual color, and reverberation, each reading its parameters from z through a small head. The entire system is trained end-to-end on content-invariant pairs — the reference and target share the same plugin setting applied to different source recordings — so the only thing z can usefully describe is the treatment, not the content.

Figure 1. Overview of TAPE. The encoder f maps a processed reference wetA to an embedding z, and small heads map z to the controls and gates of a five-module DSP chain that processes a different recording dryB. In training (dashed), the same plugin configuration θ renders A and B, and the output is compared with wetB. Information about the source of A in z cannot help reconstruct B, but no loss removes it from z.

Text-to-Effect

A frozen sentence encoder is aligned to TAPE's embedding space, so a text description can stand in for a wet reference: the projected embedding z is decoded by the same DSP inverse and applied to the dry clip below. This demonstrates that the space is indexable from outside audio, not a retrieval benchmark.
